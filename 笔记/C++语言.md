## 动态数组扩容（`MyVector` v1 · 2026-10-14）

> 内容来自你在 `MyVector.h` 顶部写的答案，整理成笔记格式。

- **现象**：扩容不能原地扩大，必须申请一块新内存 → 把旧元素拷过去 → 释放旧内存 → 让指针指向新内存。
- **为什么**：`vector` 在内存里是一块**连续空间**，原地扩大不能保证其后有足够的未使用空间；
  而且 `new[]` 分配的内存块**根本没有「原地扩大」这个操作**，标准里不存在。
- **结论**：扩容 = 申请-拷贝-释放。倍数取 **2**，摊还后 `push_back` 是 O(1)。
- **踩坑**：容量为 0 时 `capacity_ * 2` 还是 0，**永远扩不起来** —— 必须特判。

## 空容器的 `pop_back`（`MyVector` v1 · 2026-10-14）

- **现象**：空表调 `pop_back()` 该怎么办？三种选择：打印提示 / 抛异常 / 不管。
- **为什么**：**库代码不该产生输出** —— 容器不知道自己被用在哪里，一旦写 `cout`，调用方关不掉
  （污染测试输出、日志、服务器）。`std::vector::pop_back()` 对空表干脆是**未定义行为**，不做检查。
- **结论**：选 `assert(!empty())` —— Debug 下会炸并指出行号，Release 下自动消失、零开销。
  **代价**：Release 下不保护，`size_` 会回绕成 `SIZE_MAX`，之后再 `push_back` 就是堆越界。
